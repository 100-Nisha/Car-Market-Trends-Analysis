# 🚗 Car Market Trends Analysis with CarDekho Data

## 📌 Project Overview

This project analyzes used car market trends using the CarDekho dataset. The objective is to explore vehicle pricing, depreciation, ownership, fuel type, transmission, vehicle age, kilometers driven, and resale value.

The project uses Python for data cleaning, exploratory data analysis, visualization, and business insights.

## 🎯 Objectives

* Analyze used vehicle market trends.
* Identify the lowest and highest selling prices.
* Analyze vehicle depreciation.
* Identify the most frequently sold vehicles.
* Analyze fuel type and transmission.
* Study ownership patterns.
* Analyze the relationship between vehicle age, kilometers driven, and selling price.
* Analyze two-wheelers and cars separately.
* Identify exceptional vehicle deals.

## 🛠️ Technologies Used

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn

## 📊 Dataset

The project uses a CarDekho used-car dataset containing **301 records**.

Important columns include:

* Car_Name
* Year
* Selling_Price
* Present_Price
* Kms_Driven
* Fuel_Type
* Seller_Type
* Transmission
* Owner

* The dataset contains 301 vehicle records.
* Vehicle manufacturing years range from 2003 to 2018.
* Selling prices vary considerably across vehicles.
* Vehicle age and kilometers driven are important factors to consider when analyzing resale value.
* Fuel type, transmission, ownership, and vehicle model also provide useful insights into the used-car market.
